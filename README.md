# Pattern-Based Stabilizer Tripwire: Quantum Entanglement Attack Simulation

A Qiskit simulation of coherent entanglement attacks on the **five-qubit (\([[5,1,3]]\)) non-CSS stabilizer code** under the **Pattern-Based Stabilizer Tripwire** protocol.

The purpose of this repository is to demonstrate how shifted Pauli error patterns and **Syndrome Fusion Masking** prevent an eavesdropper (Eve) from extracting secret key bits via quantum entanglement. In standard QKD protocols (such as BB84), Eve can entangle an ancilla with the flying qubits and wait for classical reconciliation broadcasts. In this architecture, any transversal interaction disturbs the mixed \(X/Y/Z\) stabilizers, triggering a **50% Quantum Bit Error Rate (QBER)** tripwire while turning Eve's own disturbance into a cryptographic mask.

---

## Repository Structure

This repository contains two complementary simulation scripts:

1. **`main.py` (Without Syndrome Fusion Masking — Tripwire & Randomization Baseline):**
   * Evaluates the raw behavior of the \([[5,1,3]]\) shifted Pauli frame under a transversal CNOT entanglement attack (`eve_attack = 1`).
   * **Key Insight:** Even when Pauli pattern masking is enabled (`action = 1`), Eve's raw ancilla readout still retains deterministic correlation with Alice's initial bit via the classical relation `eve_bit ⊕ b_relation = a` (100% correlation once `b_relation` is known). However, applying Bob's stabilizer syndrome correction (`noise_correction = 1`) completely randomizes Bob's measurement (`measured_a`), driving the QBER to **50%**.
2. **`main2.py` (With Syndrome Fusion Masking — Full Key Privacy):**
   * Builds directly on the stabilizer-induced randomization observed in `main.py`.
   * Instead of letting Eve exploit `eve_bit ⊕ b_relation = a`, Alice uses the discrepancy syndrome (\(s_{\text{noise}}\)) generated by Eve's disturbance and dynamically steers/masks the final key bit via **Syndrome Fusion Masking** (\(s_{\text{total}} = C_1 \cdot s_{\text{noise}} \oplus C_2 \cdot s_{\text{part}}\)). This turns Eve's own attack disturbance into a one-time blinding mask, reducing her reconciled key correlation to **50%** (random guessing).

---

## Overview of Core Mechanisms

In this protocol, the secret key bit does not exist prior to communication; it is dynamically formed after transmission through classical reconciliation (`a_relation`, `b_relation`, and syndrome broadcasts):

* **Pauli Error Pattern Masking (`action = 1`):** Scrambles physical codeword parity using weight 3–5 Pauli operators, reducing Eve's direct raw bit match (`eve_bit == a`) from **100% down to 50%**.
* **Stabilizer Error Correction (`noise_correction = 1`):** Extracts syndromes (`XZZXI`, `IXZZX`, `XIXZZ`, `ZXIXZ`) and applies recovery gates. Decoherence from Eve's CNOT entanglement scrambles the stabilizer phases, randomizing `measured_a` and triggering a **50% QBER** alarm at Bob.
* **Syndrome Fusion Masking (`main2.py`):** Uses random binary selectors `(c1, c2)` and partial recovery syndromes (`s_part`) to dynamically flip or preserve the reconciled key bit, severing Eve's `eve_bit ⊕ b_relation = a` correlation whenever she disturbs the channel.

## Configuration Variables

You can change these variables manually in the `# Initialize` section before running either script:

```python
eve_attack = 1
action = 0
measure_method = 1
noise = 0
noise_correction = 0
```

* **`eve_attack`:**
  * `0`: Eve is not present.
  * `1`: Transversal 5-qubit CNOT entanglement attack.
  * `2` *(in `main2.py`)*: 5-to-1 controlled-parity probe (`eve_apply_case2`).
* **`action`:** `0` means no Pauli error pattern is used; `1` means weight 3–5 Pauli error pattern is applied.
* **`measure_method`:** `0` means measuring after decoding; `1` means parity measurement without decoding *(recommended to keep at `1`)*.
* **`noise`:** `0` means no natural channel noise; `1` means single-qubit natural noise is injected *(note: in `main2.py`, stabilizer correction is always active)*.
* **`noise_correction` *(in `main.py`)*:** `0` means Bob skips stabilizer error correction; `1` means Bob applies stabilizer syndrome correction.

## Test Scenarios & Expected Results

### 1. `main.py` (Without Syndrome Fusion Masking)
1. **`eve_attack = 0` (any values for other flags):** Alice and Bob match **100%** (0% QBER).
2. **`eve_attack = 1`, `action = 0`, `noise = 0`, `noise_correction = 0`:** Eve extracts Alice's full bit via entanglement (`100%` knowledge). Bob's QBER is **0%**.
3. **`eve_attack = 1`, `action = 0`, `noise = 0`, `noise_correction = 1`:** Eve still extracts Alice's full bit (`100%` knowledge), while stabilizer correction randomizes `measured_a`, driving Bob's QBER to **50%**.
4. **`eve_attack = 1`, `action = 1`, `noise = 0`, `noise_correction = 0`:** Eve's direct readout `eve_bit` matches `a` **50%** of the time, though she still retains full correlation via `eve_bit ⊕ b_relation = a`. Bob's QBER is **0%**.
5. **`eve_attack = 1`, `action = 1`, `noise = 0`, `noise_correction = 1`:** Eve still satisfies `eve_bit ⊕ b_relation = a`, while Bob's stabilizer correction completely randomizes `measured_a`, forcing a **50% QBER** tripwire.

> **Key Contrast (Scenario 4 vs. Scenario 5):** Comparing Scenario 4 (`noise_correction = 0`, **0% QBER**) with Scenario 5 (`noise_correction = 1`, **50% QBER**) proves that **stabilizer syndrome measurements drive the tripwire alarm**. When `noise_correction = 0` (0% QBER), no logical error is induced at Bob, allowing Eve to quietly collect full correlation via `eve_bit ⊕ b_relation = a`. Turning on stabilizer correction (`noise_correction = 1`) converts Eve's entanglement into a logical error that randomizes `measured_a`.

### 2. `main2.py` (With Syndrome Fusion Masking)
1. **`eve_attack = 0`, `action = 1`:** Alice and Bob reconcile **100%** of key bits accurately (`a == measured_a`), even across randomized `(c1, c2)` and `s_part` masking rounds.
2. **`eve_attack = 1`, `action = 1` (Transversal Attack):** Eve's transversal CNOT attack triggers a **50% QBER** at Bob, and Syndrome Fusion Masking uses the resulting syndrome disturbance to randomize the reconciled key bit—destroying the `eve_bit ⊕ b_relation = a` correlation and reducing Eve's knowledge rate to **~50%**.
3. **`eve_attack = 2`, `action = 1` (5-to-1 Controlled-Parity Probe):** Eve's $n$-to-$1$ parity probe (`eve_apply_case2`) preserves the stabilizer syndrome frame and yields **0% QBER** at Bob—mirroring Scenario 4 of `main.py` where the absence of a logical error allows parity extraction. This demonstrates why **delayed $P_{\text{global}}$ disclosure** (or dummy-qubit coordinate hiding) is required alongside Syndrome Fusion Masking to block $n$-to-$1$ parity attacks in transit.

## Output File

After 100 simulated blocks, each script exports `eveattack1(5).xlsx` containing:
* **Per-block data:** Reconciled key bits (`a`, `measured_a`), Eve's readout (`eve_bit`), raw bits (`given a`, `sent a`), reconciliation parities (`a relation`, `b relation`), applied Pauli masks (`given_Pauli`), channel errors (`natural_error`), and syndromes (`ancilla_bits`).
* **Aggregate statistics:** Syndrome distribution rates (`0000`–`1111`), multi-qubit error rates, no-error rates, statistical variance, and `eve knowledge rates`.
